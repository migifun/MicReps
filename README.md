# MicReps

人前で話す練習のための、Mac用の録音アプリです。録音するだけで、次のことを自動で行います。

- 文字起こし
- チャプター分け
- 話し方の分析(フィラー・間・抑揚・声の大きさ・話す速さ)
- 文の見直し

処理はすべてこのMacの中で行います。音声も文字も外部のサービスに送りません。

## できること

- **録音と再生**
  - 録音・一時停止・再開ができます。
  - 再生は15秒戻る・進む、速度の変更ができます。
  - 録音中にアプリが強制終了しても、音声は残ります。
- **取り込み**
  - 手元の音声・動画ファイルを取り込めます(wav・m4a・mp3・flac・ogg・mp4・movなど)。
  - ⌘O、ウィンドウへのドロップ、Finderの「このアプリケーションで開く」のどれでも使えます。
- **文字起こし**
  - 文ごとに時刻を付けます。
  - 「読む」表示: 文を押すとそこから再生し、再生中は今の文を示します。分析の印も本文に重ねて出します。
  - 「テキスト」表示: 自由に選んでコピーできます。
- **チャプター**
  - 話題の変わり目で章に分け、見出しを付けます。
  - 章を押すと、その位置へ移動します。見出しの変更・削除・作り直しもできます。
- **話し方の分析**
  - フィラー(「えっと」「あの」など)、間、抑揚の幅、声の大きさ、話す速さ、口癖を測ります。
  - 指摘(長い間、抑揚が小さい文、語尾が弱い文、速い文など)を一覧にし、押すとそこから再生します。
- **文の見直し**
  - 決まりで見つけるもの: 長い文、名詞を飾る言葉が続く文、言い直し
  - AIで見つけるもの: 本題から外れた文
  - 長い文には、AIによる言い直しの例を付けます。
- **振り返り(⌘⇧T)**
  - 録音ごとの数値の変化をグラフで並べます。
  - いちばん新しい録音を、それまでのふだんの値と比べます。
- **書き出し**
  - 音声(m4a)
  - 文字起こし(テキスト、時刻つき、チャプターつきMarkdown)
  - 字幕(SRT)
  - 話し方の分析(Markdown)

## 動かすのに必要なもの

| 必要なもの | 用途 |
|---|---|
| Apple シリコンのMac、macOS 26 以降 | アプリ全体 |
| Xcode 26 以降 | ビルド |
| 日本語の文字起こしモデル | 文字起こし。初回にmacOSがダウンロードする(アプリ内のボタンから始められる) |
| Apple Intelligence をオン | チャプターと文の見直し(システム設定 >「Apple IntelligenceとSiri」)。オフでも、録音・文字起こし・話し方の分析は使える |

## ビルドと起動

1. `MicReps.xcodeproj` を Xcode で開きます。
2. スキーム `MicReps` を選び、実行(⌘R)します。

コマンドで作る場合は次のとおりです。

```bash
xcodebuild -project MicReps.xcodeproj -scheme MicReps -configuration Release -derivedDataPath build/dd build
open build/dd/Build/Products/Release/MicReps.app
```

- **署名:** 初期設定では、そのMacだけで動く署名(ad-hoc)です。この署名では、作り直すたびにマイクの使用許可を聞かれることがあります。避けたいときは、`Config/Signing.xcconfig` で自分の開発チームを指定してください。
- **テスト:**

  ```bash
  xcodebuild -project MicReps.xcodeproj -scheme MicReps -derivedDataPath build/dd test
  ```

## データの保存場所

| 版 | 保存場所 |
|---|---|
| 通常の版 | `~/Library/Application Support/MicReps/` |
| 開発用(Debug)の版 | `~/Library/Application Support/MicReps-Debug/` |

開発中に、普段使いの録音を壊さないよう、場所を分けています。
- 録音は `recordings/` に m4a で保存します。
- 文字起こしや分析の結果は、同じ場所のデータベース(SwiftData)に保存します。

## 使っている技術

外部のライブラリは使っていません。すべて Apple の標準フレームワークです。

| 処理 | 使っているもの |
|---|---|
| 録音 | AVAudioEngine で PCM の CAF に書き続け、完了後に AAC(64kbps)の m4a へ変換する |
| 文字起こし | Speech フレームワークの SpeechAnalyzer と SpeechTranscriber(オンデバイスの音声認識) |
| 声の分析 | Accelerate(vDSP)で20ミリ秒ごとの音量を測る。声の高さはYIN法。話す速さは、読みがなに直して音の数を数える。AIのモデルは使わない |
| フィラー・言い直し・長い文 | 正規表現と NaturalLanguage(単語の切り分け)による決まりで判定する |
| チャプター・脱線・言い直しの例 | Foundation Models フレームワーク(Apple Intelligence のオンデバイスモデル)。決まった型で答えさせる。チャプターは、聞き方を変えた3回の答えの多数決で決める |
| 保存 | SwiftData |
| 画面 | SwiftUI、AppKit(NSTextView)、Swift Charts |

設計の考え方と、実際に測った結果は [DESIGN.md](DESIGN.md) にあります。話し方の分析の調査と計画は [ROADMAP-話し方分析.md](ROADMAP-話し方分析.md) にあります。

## 制限

- **話し方の分析は日本語向けです。** フィラーの辞書や、話す速さの数え方は日本語を前提にしています。文字起こしの言語は設定で変えられます。
- **精度について:** 文字起こしとチャプターの精度は、主に合成音声と自作の原稿で測った値です。実際の声・雑音・複数人の会話では、精度が下がることがあります。
- **AIの出力について:** AIの判定と言い直しの例は、参考として使ってください。言い直しの例は、まれに意味が変わります。
